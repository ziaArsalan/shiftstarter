One design choice worth highlighting: everything the website does goes through a versioned API — 47 endpoints planned across eleven areas. The website is just one client of that API. When you’re ready for a mobile app, it plugs into the same backend; we don’t rebuild the business logic. The mobile app itself isn’t in this quotation, but this keeps that door open at no extra cost.
