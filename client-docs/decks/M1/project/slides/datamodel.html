This is the heart of the marketplace. A pharmacy has one or more locations; each location hosts shifts; workers apply to shifts; an accepted application becomes a booking. Everything else hangs off the booking — payments, reviews, disputes and the message thread between the two sides. Around each worker we store their profile, credentials and availability. In total that’s 16 tables, and the first database migration is already generated, so Milestone 2 starts on a real database.
