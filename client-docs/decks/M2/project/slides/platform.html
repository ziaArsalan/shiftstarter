04

On our November 12 call we agreed to build on Supabase, and Milestone 2 was rebuilt on it. Supabase now handles sign-in and password reset, hosts the database, and stores licence files privately. On top of that, the database itself enforces that each pharmacy only sees its own data, so privacy doesn’t rely on the website alone. The API server and website are the same as planned, so a mobile app can still reuse everything later.
